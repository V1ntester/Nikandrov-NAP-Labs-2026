## Защита
При защите лабораторной работы было необходимо визуально перевернуть блок с калькулятором, что было реализовано
с помощью свойства transform()

```
.calculator {
  background-color: #ffffff;
  padding: 40px 30px;
  border-radius: 16px;
  transform: rotate(180deg);
}
```
